# Trabalho NP1 — Introdução à Programação em Python

Repositório: [iies-eng-2026-2](https://github.com/eduardo-arcade-metrics/iies-eng-2026-2)

---

## Descrição

Esta atividade é composta por três exercícios práticos de programação em Python, cada um abordando um problema de engenharia real. Os exercícios devem ser resolvidos no Google Colab, um ambiente de notebook online que já está disponível para todos com conta Google.

Você pode e deve usar ferramentas de IA para apoiar a resolução. O que será avaliado não é se você usou IA, mas se você entende o que está entregando.

---

## Exercícios

| Exercício | Tema | Conceito principal |
|-----------|------|--------------------|
| 01 | Classificação de carga em cabos | if / elif / else |
| 02 | Consumo de combustível em rota | for com range |
| 03 | Controle de temperatura de reator | while |

Cada exercício tem seu próprio enunciado dentro desta pasta, em arquivo `.md` separado.

---

## O que deve ser entregue

Para cada exercício, um arquivo `.ipynb` resolvido e funcional, sem erros de execução. Todas as células devem estar executadas e com as saídas visíveis no momento do envio. Cole dentro da pasta entregas

---

## Nomenclatura dos arquivos

Siga exatamente o padrão abaixo, substituindo `nome-sobrenome` pelo seu nome em letras minúsculas e sem acento:

```
ex01-classificacao-cabos-nome-sobrenome.ipynb
ex02-consumo-combustivel-nome-sobrenome.ipynb
ex03-controle-temperatura-nome-sobrenome.ipynb
```

Exemplo para João Silva:
```
ex01-classificacao-cabos-joao-silva.ipynb
ex02-consumo-combustivel-joao-silva.ipynb
ex03-controle-temperatura-joao-silva.ipynb
```

---

## Como entregar

1. Crie uma branch no repositório com o seguinte nome, usando seu nome real:

```
np1/nome-sobrenome
```

Exemplo:
```
np1/joao-silva
```

2. Dentro da branch, coloque seus três arquivos no caminho:

```
tarefas/04-trabalho-np1/entregas/nome-sobrenome/
```

3. Abra um Pull Request da sua branch para a branch `main` com o título:

```
NP1 - Nome Sobrenome
```

Não faça merge. O Pull Request aberto já conta como entrega.

## Critérios de avaliação

Cada exercício vale um ponto. Dentro de cada exercício, serão avaliados:

- O código executa sem erros
- O resultado está correto para os dados fornecidos
- As células estão organizadas na ordem proposta pelo enunciado
- A saída está legível e identificada

Código que executa mas produz resultado errado recebe nota parcial. Código que não executa recebe zero no exercício correspondente.


---

## Observação sobre uso de IA

O uso de ferramentas como ChatGPT, Claude ou Copilot é permitido e esperado. O que não é permitido é entregar um notebook que você não consegue explicar. O professor pode, a qualquer momento, pedir que você explique qualquer linha do que entregou.
Se usou LLMs para gerar o código, reserve um espaço para colar o prompt usado.
